───────────────────────────────────────────────────────────────
  🔄 HOW IT WORKS
───────────────────────────────────────────────────────────────

CLIENT SETUP:
  1. Client connects Meta Ads via OAuth
  2. Client goes to Meta Ads Manager
  3. Client sets daily budget: $50 in Meta Ads Manager
  4. Client tells APEX: "I set $50 daily budget"
  5. Client enables worker features

WORKER EXECUTION:
  1. Worker picks up work_request: "Run Meta Ads campaign"
  2. Worker reads integrations table for this user
  3. Worker sees: daily_budget = "50", enable_ads = true
  4. Worker uses client's Meta Ads access token
  5. Worker creates campaign with $50 daily budget
  6. Meta Ads charges CLIENT'S payment method
  7. Worker updates work_request: completed

AD SPEND FLOW:
  Meta/Google → Charges CLIENT directly
  APEX → Never touches money, only creates campaigns
