───────────────────────────────────────────────────────────────
  🏗️ How It Works
───────────────────────────────────────────────────────────────

CLIENT FLOW:
  1. Client logs in → Dashboard
  2. Clicks "Integrations" tab
  3. Sees Meta Ads, Google Ads, Instagram cards
  4. Clicks "Connect" on Meta Ads
  5. (OAuth flow - coming once App IDs configured)
  6. Token stored in integrations table
  7. Status: disconnected → connected

WORKER FLOW:
  1. Worker picks up work_request
  2. Job type: "multi_channel_campaign"
  3. Reads integrations table for this user
  4. Gets Meta Ads access token
  5. Calls Meta Ads API with CLIENT'S token
  6. Creates campaign in CLIENT'S ad account
  7. Ad platform charges CLIENT directly
  8. Updates work_request: completed

AD SPEND FLOW:
  Client owns ad account
    → APEX has access token
    → Worker creates campaign
    → Ad platform charges CLIENT
    → APEX never touches money

───────────────────────────────────────────────────────────────
  💰 Key Business Model
───────────────────────────────────────────────────────────────

Traditional Agency:
  Client → Pays Agency → Agency Pays Platform
           (markup)       (ad spend)

APEX Model:
  Client → Connects Account → APEX Creates Campaigns
                              ↓
                    Platform Charges CLIENT

APEX is a SYSTEM, not an agency.
Clients keep control. APEX automates execution.
